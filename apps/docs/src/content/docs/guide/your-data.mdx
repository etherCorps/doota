Your mail is yours, and you can take it with you. Doota exports a whole mailbox
as an **`.mbox`** file — the standard mail-archive format that Thunderbird,
Apple Mail, and most other mail apps can import.

Open **Account → Mail** and find **Export mailbox**, then hit **Export mailbox
(.mbox)**. Doota confirms which address you're exporting, gathers your messages,
and gives you a **Download** button when it's ready. You'll see how many messages
it packed and when.

<Aside type="caution">
The export file contains your **decrypted** mail — that's the point, so you can
read it anywhere. The download link works for **15 minutes** and anyone with the
link can read the file while it's valid, so download it somewhere private and
don't pass the link around. After it expires, just run the export again.
</Aside>
